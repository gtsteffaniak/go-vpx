# Private DC caller zero-product guard review

Exact baseline `10caaa67ed53f8c3c1248f20070e5a4117245852`; only candidate production change is `internal/vp8/decoder/reconstruct.go`. All backend kernels remain byte identical. No ROOT, Git, README, dependency or assembly edits were made.

The guard is correct for the reviewed contract: each int16 product fits int32; an OR equal to zero means both products are zero. Rounded zero adds identity to every byte. The complete stride>=8 4x8 window proves disjoint rows and preserves the original access validity. Luma still evaluates its original window slice before the new predicate. Skipping the write cannot change aliased backing because every original store writes the same byte; no coefficient/EOB cleanup follows the skipped call. Nonzero, malformed, disabled and portable paths retain the original fallback and panic order. Full-transform dispatch is unchanged.

Independent external tests retain exact pinned-parent caller functions with only their names changed. They compare the entire backing allocation, qcoeff, EOB, dequant, and exact recovered panic string. Each mode passed 41,920 cases: 38,080 shape/stride/alignment/length/capacity/destination-alias states, 2,880 seeded/floor/full-transform/input-alias states, and 960 nil/index/partial-error states. Candidate native ordinary, native race/checkptr2, purego, nosimd, and AMD selected/off checkptr2 all pass (251,520 candidate comparisons), plus 41,920 immutable parent self-checks. AMD runs are Rosetta correctness only. No test thresholds were weakened. No failures occurred in these requested tests; a sandbox-denied `ps` inspection did not affect the completed checks.

The standalone shared B.Loop fixture covers 18 actual internal-caller workloads: luma seeded-zero/mixed/nonzero and chroma zero-DC/mixed/nonzero, each with pitches16/37/1312. The zero luma uses seeded=true and floor1 to force parent DC dispatch; chroma zero uses EOB1. It restores identical touched output rows each iteration and checks frozen-parent pre/post full backing and every input array, then consumes a checksum. The row reset is included in the measured operation. All36 excluded one-shot preflights and all216 measured samples pass their state oracles with zero B/op and allocs/op.

Six alternating AB/BA rounds used Apple M4 Max, official Go1.27.2 SIMD, CGO1, PGOoff, GOMAXPROCS1, 75ms. Luma seeded-zero medians improve1.277–1.305x (18/18 faster pairs); mixed improves1.072–1.106x (18/18). Luma nonzero regresses to0.961–0.981x (16/18 slower pairs). Chroma zero improves1.156–1.177x (17/18 faster pairs; pitch37 has a0.8803x outlier). Chroma mixed regresses to0.952–0.962x, nonzero to0.949–0.970x; every one of those36 pairs is slower. No case reaches1.5x. These results show a real workload tradeoff; they establish no whole-codec or assembly comparison.
