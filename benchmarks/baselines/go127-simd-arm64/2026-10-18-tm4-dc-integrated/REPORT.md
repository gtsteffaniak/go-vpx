# Final combined ARM TM4, loop-filter and DC-pair validation

Strong parent is exact merged PR47 `d2610cd0747edd72f7656068dfd4604d29e45307`, tree-equal to tested head `b6209532fbc30cf9567e0cdc78a21d61a60fe900`. Independent snapshot clones were used; earlier frozen experiment sources were not mutated. All source hashes bind the final root bytes. The result is measured as a combined change; isolated gains are not summed or multiplied.

Apple M4 Max; official Go 1.27.2; GOEXPERIMENT=simd; CGO=1; PGO off; GOMAXPROCS=1. Six uniformly built test binaries (DSP and decoder for each reference) and three CLIs have build-command, build-info, SHA256/size receipts. The same public TM27, DC18 and picker10 fixtures were copied byte-identically to each reference. All 165 one-shot output/canary oracles passed with zero allocations before timing. One-shot durations are not performance evidence and can omit ns/op when clock resolution yields zero.

The exclusive kernel window ran six balanced three-way orders at 100 ms/case: 990 samples, every pre/post public output oracle passing, 0 B/op and 0 allocs/op throughout. TM4's nine case medians improve 2.5389265433–2.6222013170x over merged PR47; all 54 paired comparisons improve at least 2.5001801802x. TM4 also beats active old NEON in all 54 pairs (minimum 1.0727927928x), with case median speedups of 1.0898444648–1.1224835372x.
