## Production scope and proof

Only `internal/pixel/sad_amd64.go` changes production code. The exact original width8 dispatch stays before the new wide guard. Supported new geometry is width32/64, height1..64, nonnegative independent strides below2^30, Enabled=true, actual archsimd AVX2=true, and complete visible windows in both slices. Every failed guard retains the original narrow/generic behavior. Original scalar-disabled behavior is unchanged. Inputs are read-only: exact aliases, overlapping inputs, repeated/overlapping rows, unequal strides and arbitrary byte alignment remain valid. Invalid visible lengths decline before any new unsafe load; the original fallback preserves its slicing/panic order and diagnostics, including short slices with spare backing capacity, nil, unused negative/MaxInt stride at h1, and unusual geometry.

Accepted geometry proves `(h-1)*stride+width < 2^36` before offset multiplication. Exact32-byte LoadArray operations are within the validated visible windows; neither row pointer advances beyond the object. Go unsafe.Pointer values retain the backing objects; no uintptr round-trip is used. Each row width32 uses one256-bit VPSADBW packet; width64 uses two independent accumulators. Every PSADBW uint64 lane is at most130560 per strip, at most261120 after adding strips, with complete total≤1044480. The final Uint32 reinterpretation has zero high32 halves, all low halves and the signed-int32 reduction remain below2^31, so the reduction is exact.

The result reaches a general register before one direct VZEROUPPER. Bounds-valid fast paths have no language-level panic or helper call. Unsupported/invalid paths leave before any YMM instruction. This does not promise cleanup for an externally forged invalid Go slice/dangling pointer outside the preexisting slice contract.

The mechanism extends the already copied GoAV1 128-bit PSADBW dataflow to the SDK's Uint8x32.SumOf8AbsDiff; no new GoAV1/Gopus dependency is added. AVX2 is sufficient: no AVX512 assumption or ZMM instruction is used. Native CI must record actual CPU feature selection and compare only within its same job/CPU.
